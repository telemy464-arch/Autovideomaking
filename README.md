## 🌟 পরিচিতি
**AI Video making By Mizan** হলো একটি অত্যাধুনিক, সম্পূর্ণ স্বয়ংক্রিয় AI ভিডিও মেকিং প্ল্যাটফর্ম। এটি সম্পূর্ণ বাংলা ভাষায় উচ্চমানের ভিডিও (YouTube Shorts, Instagram Reels, TikTok ও ফুল-লেংথ ভিডিও) তৈরি করার জন্য ডিজাইন করা হয়েছে। 

এতে ব্যবহৃত হয়েছে **AntiGravity মাল্টি-এজেন্ট আর্কিটেকচার**, যা ৪টি স্বতন্ত্র ইন্টেলিজেন্ট এজেন্টের সমন্বয়ে মানুষের কোনো হস্তক্ষেপ ছাড়াই বিষয় নির্বাচন থেকে শুরু করে ফাইনাল রেন্ডারিং পর্যন্ত সম্পূর্ণ কাজ স্বয়ংক্রিয়ভাবে সম্পন্ন করে।

## 🧠 AntiGravity Agent — মূল সিস্টেম

| এজেন্ট | নাম ও ভূমিকা | মূল দায়িত্ব |
|---|---|---|
| 🔹 **এজেন্ট ১** | **টপিক জেনারেটর (Topic Generator)** | ব্যবহারকারীর বিষয় বা নিচ থেকে ৫টি সেরা, ক্লিকযোগ্য ও ভাইরাল বাংলা শিরোনাম তৈরি করে। |
| 🔹 **এজেন্ট ২** | **স্ক্রিপ্ট রাইটার ও কোয়ালিটি চেকার** | প্রথম ৫ সেকেন্ডের অব্যর্থ হুকসহ কথ্য বাংলায় স্ক্রিপ্ট লেখে এবং মান পরীক্ষা করে (স্কোর < ৭ হলে স্বয়ংক্রিয়ভাবে পুনরায় রিরাইট করে)। |
| 🔹 **এজেন্ট ৩** | **মিডিয়া কালেক্টর (Media Collector)** | Pexels ও Pixabay থেকে প্রতিটি সিনের সাথে মিলিয়ে ফ্রি HD স্টক ভিডিও ক্লিপ ডাউনলোড করে। |
| 🔹 **এজেন্ট ৪** | **ভিডিও কম্পোজার (Video Composer)** | Edge-TTS বাংলা ভয়েস, বাংলা ফন্টের সাবটাইটেল, ব্যাকগ্রাউন্ড মিউজিক (অটো-ডাকিং) ও ট্রানজিশন মিলিয়ে ফাইনাল MP4 ভিডিও তৈরি করে। |

## ✨ প্রধান প্রধান ফিচারসমূহ

- ⚡ **এক ক্লিকে সম্পূর্ণ ভিডিও:** যেকোনো একটি বিষয় লিখলেই কয়েক মুহূর্তে রেডি ভিডিও তৈরি।
- 🇧🇩 **বাংলা ভাষা ফার্স্ট:** স্ক্রিপ্ট, ভয়েসওভার, সাবটাইটেল এবং ইউজার ইন্টারফেস—সবকিছু সম্পূর্ণ বাংলায়।
- 📐 **মাল্টি-ফরম্যাট সাপোর্ট:** 
  - **9:16 (Shorts / Reels / TikTok)**
  - **16:9 (YouTube Landscape / Facebook)**
- 🎙️ **ফ্রি প্রিমিয়াম ভয়েস (Edge-TTS):**
  - নবনীতা (বাংলাদেশ - নারী)
  - প্রদীপ (বাংলাদেশ - পুরুষ)
  - তানিশা (ভারত - নারী)
  - ভাস্কর (ভারত - পুরুষ)
- 📝 **বাংলা সাবটাইটেল:** Noto Sans Bengali ও Nirmala ফন্টে স্টাইলিশ, হাইলাইট ও বর্ডারযুক্ত সাবটাইটেল।
- 🎵 **অটো-ডাকিং ব্যাকগ্রাউন্ড মিউজিক:** ভয়েসওভারের সময় মিউজিকের ভলিউম স্বয়ংক্রিয়ভাবে কমে যাবে (১০-১৫%), ফলে কথা একদম স্পষ্ট শোনা যাবে।
- 📦 **ব্যাচ জেনারেশন:** এক ক্লিকে ৫টি সম্পূর্ণ ভিন্ন ভিডিও একসাথে তৈরির সুবিধা।
- 🚫 **কোনো ওয়াটারমার্ক নেই:** সম্পূর্ণ পরিষ্কার ও প্রফেশনাল এক্সপোর্ট।
- 📂 **গ্যালারি ও লাইব্রেরি:** তৈরি হওয়া ভিডিও সহজে প্রিভিউ ও ডাউনলোড করার সুবিধা।

## 🔑 ফ্রি API Keys সেটআপ (ঐচ্ছিক কিন্তু সুপারিশকৃত)
অ্যাপটি API Key ছাড়াও বিল্ট-ইন ফলব্যাক মোডে কাজ করতে সক্ষম। তবে সর্বোচ্চ মানের জন্য:
1. **Google Gemini API Key:** [Google AI Studio](https://aistudio.google.com/) থেকে বিনামূল্যে নিন।
2. **Pexels API Key:** [Pexels API](https://www.pexels.com/api/) থেকে সম্পূর্ণ বিনামূল্যে নিন।
3. **Pixabay API Key:** [Pixabay API](https://pixabay.com/api/docs/) থেকে বিনামূল্যে নিন।

অ্যাপের সাইডবারে গিয়ে এক ক্লিকেই API Key গুলো সংরক্ষণ করে নিতে পারবেন।
